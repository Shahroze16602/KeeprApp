Collectible-looking tile for smart piles — reads like a pack to open. Chunky sticker with a stacked hard shadow.

```jsx
<PileTile label="Screenshots" count={342} detail="1.4 GB"
  accent="var(--gone-grad)" icon={<i className="ph-fill ph-scissors" />} />
```

Pass a `thumb` URL to show a real image instead of the `accent` gradient field. Grid these 2-up.
