Sticker label for counts/tags, and the big circular milestone badge for 100 / 1,000 / 10,000 photos.

```jsx
<Badge tone="reward" icon="⚡">NEW</Badge>
<Badge variant="milestone" tone="reward" icon="🏆" label="photos">1K</Badge>
```

Tones: keep / gone / reward / win / neutral / ink. Use `locked` on a milestone to show the dimmed lock state.
