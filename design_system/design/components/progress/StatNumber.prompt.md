Enormous numeral that counts up on mount — the celebration/stat house style. Never fade a number in; roll it.

```jsx
<StatNumber value={2.4} decimals={1} suffix=" GB" label="Reclaimed" gradient />
```

`gradient` paints reward-gold text. Set `animate={false}` for static contexts. Pair with `--t-mega` / `--t-colossal` sizes for slams.
