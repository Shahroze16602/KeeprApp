Round/squircle chunky icon button — the deck's big KEEP / GONE / UNDO / SUPER controls and floating chrome.

```jsx
<IconButton variant="keep" size="xl" ariaLabel="Keep" shape="circle">
  <i className="ph-fill ph-heart" />
</IconButton>
```

Variants match Button plus `glass` (blurred chrome over live photos). Sizes `sm`–`xl` (48–84px). Always pass `ariaLabel`.
