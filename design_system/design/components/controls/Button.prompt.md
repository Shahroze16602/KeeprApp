Chunky, pressable button — the primary action affordance; it depresses into its hard shadow on press.

```jsx
<Button variant="keep" size="lg" onClick={keep}>Keep</Button>
```

Variants: `keep` (warm gradient), `gone` (cool gradient), `reward` (gold gradient), `neutral` (surface), `ghost` (outline-only). Sizes: `sm` / `md` / `lg`. Use `full` to stretch, `icon` / `iconRight` for glyphs.
